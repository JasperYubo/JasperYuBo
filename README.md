## 🎮 我的作品

### ♟️ 王者之弈
国际象棋变体，每个棋子都有独门绝技：
- 王：兵全死光时会瞬移
- 后：王阵亡后变成摄政目标
- 车：两条命，会复活
- 象：能指挥斜线友军　马：最多连吃 5 子　兵：能像跳棋一样跳
- 👉 [在线玩](https://jasperyubo.github.io/king-chess/)
